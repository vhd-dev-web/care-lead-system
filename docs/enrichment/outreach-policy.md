# Outreach Policy

This repository does not send outreach.

## Preferred Channels

1. Main phone number when a concrete B2B relevance note exists.
2. Manual LinkedIn research for context.
3. Personalized follow-up after a real contact point.
4. Postal/manual one-off outreach for selected cases.

## Not Allowed In This Pipeline

- Automated cold email sequences.
- Guessed personal email addresses.
- LinkedIn mass scraping.
- Contact-form automation.
- Exporting unreviewed leads to outreach tools.

## Export Naming

`outreach_ready.csv` means ready for human review, not ready for automated sending.

Only create an Instantly-style export after explicit user approval and a passed compliance gate.
